## 简化了什么

- **没有事件页、没有事件导航、没有事件卡片、没有事件弹窗**。
- **没有 6 种历史状态**；事实是否有 citation 直接决定显示「有史料」。
- 旧网页证据不再迁入史料库；`source_version=3` 清理 web 副本，旧 `fact_evidence` 留在「网络证据」。
- 临时 ASPE source、2026 美国中期选举 event 已删除。
- 史料详情去掉右侧书目/统计栏，改成单列。
- 本组截图里仍有「新增史料」表单；该入口和找史料/加原文/引用到事实已在后续版本移除，史料库改为只读。
