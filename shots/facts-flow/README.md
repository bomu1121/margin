## 与最终包不一致的地方

- 05 / 06 / 08 来自中间态（事实库 21 条，尚未完成最后合并）；最终态看 01。
- 07 是最终合并后的记录：5 条生效 + 1 条已撤销。
- 当前 16 条历史事实里仍有一些旧粒度碎片（例如 Bush 家族复合事实 + 多条原子事实）；新的抽取 prompt 和语义归并只影响新运行，整库自动重组尚未做。
- 当前没有真实数值冲突样本；`contradicts` 由单元测试覆盖，「只看冲突」当前为 0。
