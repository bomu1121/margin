# 侧栏宽度 / 收起 / 浮层滚动条（2026-11-09）

> 目标：让左右栏像桌面应用一样可调、可收；让滚动条在不用时安静，靠近时才淡入。
> 2026-11-10 修订：滚动的显示改为用户意图门控；原生条按资格常驻隐藏，避免展开文件夹时闪一帧。
> 入口：顶栏左侧按钮（左栏）；笔记右栏标题的收起按钮 / 右边缘的展开条（右栏）。

---

## 1. 左栏（笔记库）

- 宽度范围 **180–440px**；默认 240px（≤1180px 宽窗口默认 200px）。
- 鼠标移到左右分界，出现 1px 高亮线；拖动调整；双击复位；键盘 ←/→ 每次 16px，Home 复位。
- 顶栏「页边笔记」旁新增开关，一键收起/展开；收起后主区占满，开关仍在顶栏。
- 收起后左栏内容不渲染占位（`display:none`），主区显式放第 2 列，避免 0 宽列把正文吃掉。
- 持久化：`yebian.shell.sidebar.width`、`yebian.shell.sidebar.collapsed`。
- 与 NoteList 的文件夹折叠状态分开存：`yebian.sidebar.collapsed` 仍归 NoteList；旧版本误写成 `"0"/"1"` 时启动修复成 `[]`。

## 2. 右栏（本页：事实/标注/关联/信息）

- 宽度范围 **300–560px**；默认 380px（≤1180px 默认 330px）。
- 左侧分界可拖动；双击复位；键盘 ←/→ 每次 16px，Home 复位（左箭头加宽，右箭头收窄）。
- 标题行「✕」收起；收起后留下 **28px 边缘条**，点顶部图标展开。
- 持久化：`yebian.rail.width`、`yebian.rail.collapsed`。
- ≤760px 时右栏按原响应式规则隐藏；收起状态保留，回到宽窗口后恢复。

## 3. 浮层滚动条

- 只对**纯纵向滚动**容器生效；有横向溢出的容器不加类，保留原横向滚动。
- `.yb-scroll` 按「纵向且无横向溢出」的资格常驻，不等容器当前可滚动；这样文件夹展开、列表变长的瞬间，原生条已经被隐藏，不会先闪一帧原生滚动条。
- 原生纵向滚动条隐藏；不改变 wheel / 键盘 / 触控板滚动。
- 光标靠近容器右侧 **22px** 区域时，等待 **90ms** 再显示（快速划过不闪出）。
- 显示后若 900ms 无滚动/拖动/靠近，开始 **180ms 淡出**；不是突然消失。
- 滚动时立即显示；拖动浮层 thumb 可直接滚动；thumb 最小 24px。
- **用户意图门控**：`scroll` 事件本身不显示浮层；只有 400ms 内发生过 `wheel` / `touchmove` / PageUp/PageDown/方向键/Home/End/空格 才显示。路由切换、`scrollIntoView`、列表自动展开、布局 reset 产生的 programmatic scroll 不会再闪出再消失。
- **显示来源区分**：滚动触发的条保持 900ms；hover 触发的条离开边缘 180ms 后淡出。鼠标从滚动条上移开不会把刚因滚动出现的条立刻切掉。
- **滚动条可见时改左右栏宽度**：每次拖动都会触发 `yb-scroll-rescan`，浮层立刻按新容器 rect 重排；同时 ResizeObserver 观察 active 容器。修掉了“滚动条在旧位置残留一段时间”的问题。
- 目前覆盖：笔记树、正文、右栏、事实库/详情/整理、史料库/详情、待补录队列、标签台、弹窗、合并记录、候选列表、搜索下拉、图谱弹窗。
- 新增滚动容器时，在 `src/lib/overlayScrollbars.ts` 的 `SCROLL_SELECTOR` 里加类名。

## 4. 代码位置

- `src/lib/overlayScrollbars.ts`：全局浮层滚动条管理器（扫描、hover 延迟、淡出、拖动）。
- `src/styles/panels.css`：左右栏宽度变量、拖拽手柄、收起边缘、浮层 thumb 样式。
- `src/App.vue`：左栏宽度/收起、顶栏开关、拖拽与键盘、持久化。
- `src/views/NoteView.vue`：右栏宽度/收起、边缘展开条、拖拽与键盘、持久化。

## 6. 诚实边界

- 只做了鼠标/触控板 + 键盘；没有在真实触屏上验收拖拽，`touch-action:none` 的触屏体验未验证。
- 浮层滚动条只覆盖已列出的选择器；未来新增的滚动容器需要手动加选择器。
- 用户意图窗口是 400ms；如果某个滚动完全由脚本驱动、但用户刚 wheel 过，仍可能显示一次。真实滚动/触控/键盘路径已覆盖。
- 横向滚动没有自定义浮层；有横向溢出的容器保留原生横向条（也没有隐藏纵向）。
- 最小 thumb 24px 在极长列表里会让拖动比例略失真；仍可用 wheel/键盘精确滚动。
- 左栏收起后内容 `display:none`；如果某个页面依赖左栏 DOM 尺寸（目前没有），需要重新检查。
- 没有做多窗口/多 WebView 的宽度同步；localStorage 只在本机当前 WebView 生效。
- 1040 只验了笔记页；事实/史料/队列 1040 在上一轮 UI 整改中验过，但左右栏新宽度组合没有逐页重拍。
