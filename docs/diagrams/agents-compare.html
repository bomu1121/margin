共同点

都以文本为输入；都用模型 + 工具；都写同一个本地库。

分界

AI 成稿写 note.md；溯源 Agent 写 facts / evidence。
一个产出「读的」，一个产出「信的」。

隔离

引擎、提示词、工具、任务类型分开；
只共享事实库、provider、job/checkpoint 基础设施。

你只决定两件事：写什么，信到什么程度。

其余交给 agent。两套引擎互不共享提示词和工具；
只在事实库、provider 与 job 基础设施上交汇。
