# 智能体笔记匿名盲评（2026-11-19）

## 1. 设计

- 素材：`docs/research/super-agent/TRANSCRIPT.md`（Super Agent 那期口播稿，3,348 CJK）。
- 5 份产物，去掉 YAML front matter 后匿名成 `sample-A..E.md`，放在 `%TEMP%\yebian-blind`。
- 两份独立评审（独立会话、只读这 5 个文件，不读本目录报告、不联网、不猜作者）。
- 评分项（1–5）：判断与可行动性、结构服务决策、事实与出处、可读性、图表。
- 评审被明确告知：评的是「作为一份可决策的技术笔记」，不是「信息量最大」。

## 3. 结论

1. **默认 minimal 在「可决策」维度排末位**，尽管它的 12 要点覆盖是 12/12；NOTE 只有 10/12 却排第一。覆盖度不是决策质量。
2. **research-note 是唯一同时拿到 12/12 覆盖和 7/7 决策标记的新产物**：结论 / 放弃什么 / 落地先做什么 / 明确不做 / 未解问题 / 术语 / 出处边界。它此前从没用真实模型跑过。
3. **「下一步原生 tool calling」不是这个差距的解**：差距在 genre（解释文 vs 决策文档）和取舍，不在 JSON 协议。原生工具是可靠性投资，等 10 次复测出现解析失败再谈。
4. **参考稿的外部事实不是无条件的优点**：评审 1 明确扣了 NOTE「星数、最后提交日期与决策无关且无法从 12 分钟视频推出」；research-1 的「视频未给，本文不补」反而拿到出处 5 分。当前「只用素材、不编造」的规则应当保留。

## 4. 边界

- 评审是同族模型，不是人；n=2、单素材、单次生成。
- 分数是主观 rubric，不做统计显著性；排名一致只能说明方向，不是定论。
- 匿名只去掉了 front matter；标题和文风仍可能暴露来源，评审被要求不要猜。
- 没有做「读者实际会不会按笔记行动」的行为测量。
