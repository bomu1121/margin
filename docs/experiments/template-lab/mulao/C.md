# 特朗普第二任期两年：真正危险的不是丑闻，是定规则的人自己在做生意

作者认为，特朗普第二任期走到第二年，最要命的不是民主党要查的那几桩丑闻，而是"定规则的人和从规则里赚钱的人是同一家人"——商务部管着英伟达的出口执行，部长自家的金融公司又在给承接这些算力的数据中心项目融资。这一点之所以比库什纳那种战争财更致命，是因为卢特尼克是在任上用手里的权力放松监管、从中渔利，而库什纳的生意都建在任期结束之后。最大的限定是：目前这些都还停在众议员准备发起调查、国会听证的层面，连节目对结局的措辞也只是卢特尼克"可能下台"而已。

## 卢特尼克的麻烦不在钱，而在他定规则、家里人做生意

作者认为，民主党最好下手的对象不是库什纳式的战争财，而是卢特尼克这种定规则的人和做生意的人是同一家人的位置。美国限制英伟达芯片出口，指导意见由财政部编写，发布和执行归商务部；一旦这个执行者的家人正从被监管的项目里挣钱，整套出口管制的说服力就跟着打折——国家安全这面旗子是自己打自己。

素材给的链条是：英伟达很多芯片出口到马来西亚、新加坡，放在当地的数据中心，算力再卖给别的国家的企业；那些当地公司要建数据中心、手里没那么多现金，靠发行新股融资，承销的正是卢特尼克家族旗下的坎托·菲茨杰拉德。卢特尼克的说法是"就任商务部长之前已经从自己家族旗下的多家公司卸任，股票都卖出去了，生意是家人们在打理"，节目的回应是"爹负责执行规则，儿子从中参与商业操作，你说没关系，这谁信呢"。同一条线上还有稀土：今年政府向美国稀土公司提供十六亿美元，含直接拨款和低息贷款，而菲茨杰拉德就是这家公司私募股权的主承销商；这家公司前身是德州找矿的，转做永磁体垂直整合、又去巴西找了个矿、中间走 SPAC 上市，如今仍处早期小批量试产，年营收一千多万美元、每年亏一亿多美元，节目反问"等能造出来永磁电机，得二零四零年了吧"。

政府内部的裂缝也摆到了台面上：贝森特接受采访时特意说"我们一直是忠于美国政府的"，方案提了很多，但"掌握决定权的是商务部"，商务部怎么做"你得问他们的内部流程"。节目把这读成隐藏的内部矛盾开始外露。

## 库什纳赚得更多却更难被追责，因为他的生意都开在任期结束之后

节目判断，政治杀伤力的大小不看赚了多少，而看在不在任上用手里的权力。库什纳的盘子其实比卢特尼克大得多，但公司是离开白宫之后才建的，任内只是"安排他建立关系"，所以节目说卢特尼克可能下台，特朗普因库什纳而被弹劾则"不太可能"。

具体链条是：他的投资公司从沙特、阿布扎比的公司融资五十亿美元，投巴西连锁快餐、德国智能健身、以色列租车；加沙被大肆轰炸之后，又去买以色列最大的金融集团之一凤凰金融，先收百分之五，随轰炸持续再加百分之五，成了最大股东。凤凰金融主业是保险、养老金、资产管理，手里却握着一串军工供应链：以色列最大武器制造商埃尔比特系统过去一年从国防部拿到几亿美元合同、股价是三年来的二点七倍；生产炮弹引信的公司拿到国防部一点七亿美元合同；以色列造船厂二零二四年从国防部拿到七点八亿美元合同；坦克变速箱和传动装置供应商持股超过百分之十；此外还小额投资了卖产品给以色列国防部的波音和卡特彼勒。战争打完之后他连重建都算好了，加沙沿海规划一百八十座摩天大楼、旅游区、机场，"完全复制美国在伊拉克、海地的模式"。

## 民主党真正能伤到共和党的是电价和航班，不是丑闻

丑闻只能伤到个人，账单能伤到政党，所以民主党的火力压在基建上：数据中心推高居民电价、空管系统老旧导致大面积航班取消，这两件事选民能直接感受到，不需要新证据，只要把州里已经开过的听证搬到国会。

素材给的路径是：拜登时期的 AI 行政命令要求大模型公司发布新模型前先做国家安全测试、把结果上报联邦政府，还要打击深度伪造，特朗普上台后立即废除、给 AI 松绑，并力推加强化石能源供应、电网扩容的能源法案；民主党的打法是问化石能源过没过环保评估、数据中心推高居民用电要不要听证——数据中心扎堆的弗吉尼亚、俄亥俄已经开过好几轮，升级到国会不过是"水到渠成"。航班这边，上周末全美大面积延误、每天取消几千上万架次、持续三四天才缓解，起因是用了三五十年的空管系统在升级、更换路由器时出了故障；交通部长肖恩·达菲先为设备升级要了一百二十五亿美元、国会批了，几个月后说升级在做、再要三百亿，出事之后又说"你看，这说明升级的力度还不够啊"，并追加两百亿。

限定也清楚：节目自己说这事儿"还真不能怪现任的政府"，拜登时期同样发生过全美航班取消，只是只持续一两天；它顺手批评左翼媒体双标——援乌大方、升级国内设备却连嘲带讽。特朗普在菲律宾被问到航班时的回答是"这就是生活，当你强大、有权有势、拥有巨额财富时，这种事情就会发生，这很正常"，节目认为这答得驴唇不对马嘴。

## 换掉威尔斯只换了忠诚度，中期选举输球的原因一个没动

从威尔斯换成米勒，解决的是"听不听得懂特朗普想说什么"，不是"选民为什么不投共和党"。作者认为中期选举输在候选人、生活成本、资金分配三件事上，都不是换个幕僚长能改的，所以照这么弄，"两年之后还得来一次"。

素材里，选举结果出炉后特朗普情绪失控、当众向威尔斯大声咆哮，把人骂出办公室、门关了还大骂不止；接任的米勒才四十一岁，第一任期就在幕僚团队里、经常写讲稿，"可以说是肚里的老蛔虫了"，跟中途加入的威尔斯不同，两人是"真的信念组合"，下台后几乎每天通电话，竞选八字还没一撇就在讨论第二任期的施政纲领，连加拿大、格陵兰都算进去了——他太太的反应是"这傻子又忘了吃药了"。选举本身的问题则在别处：战场州的候选人没一个有号召力、没人能回应生活成本；资金上德州帕克斯顿丑闻缠身、"明显扶不起来"，共和党还非要投、注资一点五亿美元，却忽略堪萨斯、南卡、密西西比几个深红州，到最后时刻才紧急挪钱，"也为时已晚"；马斯克说中期选举给共和党投入了四亿美元，节目紧跟一句"何止是愚蠢，简直是愚蠢"。

不过这句"自大和愚蠢"后面，节目自己加了括号——"跟两年前的民主党差不多"，所以它更像两边都骂的评论，不是对共和党的单独诊断。

## 特朗普剩下两年要补的是高物价的说法，而民主党已经把解释写好了

外交场合的风光换不来国内选票。节目判断，两年后决定胜负的是谁能对高物价拿出一套说法，而特朗普现在给的还是话术、民主党那边已经是一份成型的清单，所以接下来稳住团队、敲定预算、调整选举策略，本质上都是在给这一句话腾地方。

素材里，特朗普在深圳 APEC 受到高规格接待、与中俄两国领导人坐在一起面对面座谈、事后发表中俄美元首和平宣言，但一上回国的飞机就得稳住白宫团队、敲定明年预算、调整选举策略、拿出应对高物价的方案或者说话术——"谁都知道应对高物价是话术嘛，关键你得先有一套"。民主党的清单是物价、关税、政府官员自己发财、大型企业垄断、数据中心、学生贷款。

限定在节目自己嘴里：它也承认这些"的确是事实，换民主党上来也解决不了"，差别只在站位——"谁让民主党在台下好说话呢"。它引的德州民主党参议员塔拉利科那句"全世界的钱加起来也敌不过人民的力量"，节目认为这话在两年后同样适用。
