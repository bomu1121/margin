# 深圳三国峰会不是雅尔塔2.0，它只是给停不下来的世界贴了一张创可贴

节目判断，这场深圳APEC上的中俄美元首会面不是雅尔塔式的瓜分，而是一次把既有格局写成文本、并对外宣告大国不离婚的稳定动作。最强的理由是作者用的尺子——实力决定席位——量下来今天的美俄都不够格：一个中期选举失败后只剩两年跛脚，一个还在乌东泥地里啃不动，中国真要当霸权没必要带两个累赘。最大限定也来自作者自己：这四条约等于"动脉大出血的时候贴上的一枚创可贴"，峰会之外每个国家都在错误的道路上狂奔，谁也停不下来。

## 深圳峰会不是雅尔塔2.0：按席位规则，美俄已不够格和中国同桌分赃

作者认为，把深圳会面读成"雅尔塔2.0"是欧洲人的自我恐吓。这个判断重要，因为一旦美俄确实没有能力与中国做大交易，欧洲那整套"被划进势力范围"的恐惧就落空了，他们真正该怕的东西在别处。

他借的是雅尔塔的原教旨规则：实力决定谁上桌。作者用"你有几个师啊？你要不还是去小孩那桌吧"形容蒋介石的位置，然后说今天的美俄在中国眼里"几乎和当年罗斯福、斯大林眼里的蒋介石不相上下"。依据是一首词里的对照："一个是在伊朗门口，海军差点哗变的阆苑仙葩，一个是和乌克兰在泥地里缠斗的美玉无瑕"，接着是"一个中期选举失败，往后两年唯有枉自嗟；一个啃不动乌东故土，国家安全只能空牵挂；一个是跛脚的总统，一个是穷苦的当家"。由此推出的结论很直白："中国如果真的想当霸权，干嘛还要带两个累赘一起呢？"

但作者并没有说三国毫无默契：他判断三方"有足够的默契和互信"，"大家都想多吃一口，但是都不会为了多吃一口而打起来"——所以不是没有合作，而是合作的层级轮不到瓜分世界。另外，美国在川普人还在中国的时候试射了"压箱底儿的民兵洲际导弹"，这份默契本身也是有上限的。素材在"被西方，特别是欧洲的媒体在有意识地描述成是这个"处转写中断，随后接"实力决定世界的未来走向"，缺口原样保留，不作补写。

## 三国坐在一起，真正管用的是让中小国不敢提前烧冷灶

作者认为这场峰会最大的产出不是条款，而是一个信号：中美不离婚。这个信号是发给那些正在整军备战的小国的——别提前烧冷灶，别想着在中美对峙的情景下两头套利。

家庭比喻是他给出的原话逻辑：这几年的中美元首会面，最大的作用就是告诉全世界，"爸爸和妈妈现在虽然感情不好，经常吵架，而且已经到了分居的地步，但是爸爸妈妈不离婚"。之所以要反复发这个信号，是因为底下这层土壤：2020年疫情叠加美元加息，全世界经济进入"速冻时代"，法国、德国、西班牙大量民众因物价太高上街，澳大利亚很多地方"已经开始字面意义上的吃不上饭"，日韩被美国游资"割了一茬又一茬"，软银集团、铠侠都出现了超过百分之十一的大跌。作者给出的总量判断是：全世界一百八十多个国家和地区中有三分之一正在被战火炙烤。

在作者的点名里，冒险者已经动手了：朝鲜主动接通了横跨鸭绿江的大桥，胡塞组织开始光明正大地向沙特施加压力，非洲的卢旺达"疯狂地借钱，疯狂地卖矿"，把钱换成火力再去刚果领土上换更多钱；背后是美国"不负责任地开始落地唐罗主义，开始从全球撤退"。

## 日本把冷落读成强硬政绩，韩国把合影顺位读成大国地位

接待礼仪的落差在作者看来不是失误而是安排，而日韩各自的解读恰好标出了它们在格局里的位置：日本的赢法是话术，韩国的荣耀是别人批准的。

事实层面：日本官方抱怨高市早苗在深圳下飞机时，迎接其他国家元首的仪仗队里有少男少女挥舞鲜花，而她落地时"只有红毯和两侧的三军仪仗队"；登机梯的铺设"似乎是用了心思的，这个落差确实有点高"。作者说这不是为难，而是"提前给你享受高市早苗的待遇"，对日本"已经是非常规的优待"，因为多数中国人准备的"肯定不是鲜花和欢呼"。日本的反应是把被冷落当成政绩——说明高市早苗"真的执行了对华强硬且毫不妥协的政策"，说明她"没有对日本人当面一套背后一套和中国暗中勾结"；作者的评价只有一句："输有输的赢法。"

韩国这边，李在明夫妇接机时"受到了几乎和美俄同级别的待遇"，合影被安排到"前排中央，川普身边"，顺位是韩美中俄；韩国网民一边笑话日本，一边感慨自己得到了大国地位。作者的判断是：韩国所谓的大国地位"是那个真正的大国批准的"，"韩国这种小国在什么时候都无法主宰自己的命运"。

## 欧洲的雅尔塔恐惧找错了对象，柏林那场谴责会只是失意者抱团

作者认为欧洲既高估了美俄、又看错了宣言的要害，所以柏林那场会更像仪式而不是政治。这个判断的意义在于：如果三巨头根本谈不出势力范围，欧洲真正该紧张的是宣言里关于规矩的那几条，而不是想象出来的"雅尔塔2.0"。

事实是：就在中俄美三方在深圳见面时，欧洲国家领袖和"川普的好大哥、美国俄乌问题特使维特科夫"在一个无人注意的角落组织了柏林峰会，主要目的就是谴责三人的会面。民调快要归零的德国总理默茨说深圳发生的一切"都是作秀"，德国和欧洲"严正拒绝任何通过新的雅尔塔式的协议把欧洲划分为势力范围的企图"；他的原话是：三方的和平协议没有包含任何结束俄罗斯入侵乌克兰的承诺，也没有提及乌克兰的主权或者领土完整，也没有表明在和平解决俄乌问题方面取得任何进展。他把与会国称为"自愿联盟"，给每位代表送了一片柏林墙的碎片，说这种分裂就是雅尔塔的结果，所以他坚决拒绝雅尔塔2.0，"欧洲的事情要欧洲人说了算"。

作者的反驳只有一条：雅尔塔会议之前，"罗斯福可没有制裁斯大林，丘吉尔的英国也没有禁止向苏联提供先进装备"，所以欧洲人的担心"纯粹是多余的"。至于宣言里真能让欧洲难受的部分，默茨一个字没提。

## 《和平宣言》把既有方向写成了文本，但对当下的世界只等于一枚创可贴

作者认为这四条宣言是"这个世界上最高屋建瓴的积极有为了"，实质却是把此前已经成型、只是没有公开明确的发展方向用文件固定下来，救不了正在失血的世界。

四条内容按作者读法是这样的：其一，中俄美作为真正的安理会常任理事国改革联合国，使其"更有效地履行其维护国际和平和安全的基本使命"——作者说"其实这才是欧洲国家真正应该感到恐惧和担心的事情"；其二，增加精炼石油产品的生产和供应、重申能源稳定流动的重要性，作者判断这会加重伊朗和胡塞在地区博弈中的话语权，理由是"有效控制了海峡，就能有效地影响流动性"，这后半句对伊朗"比一个中队的歼-10C都要有用"；其三，认可国家同意原则、尊重国家官员享有豁免，国际刑事法院及其他类似机构不得滥用管辖权，作者顺手给这家机构定了性——"没有绝对军事力量背书，也没有联合国授权的，合法性非常不足的条约组织"；其四，重申核战争打不赢也打不得，并就减少核风险、防止核扩散对话，作者读作是为伊朗核问题彻底解决、以及防止日本和韩国从美国手里拿到核武器做准备。

限度也在此：中国以每年一万亿美元的规模获得贸易顺差且"还是在不断地升高"，作者引比亚迪王传福的话"我赢你输的路子是走不远的"并认为"非常正确"，但同时承认外贸"真的停不下来"，因为别国的工业规模和生产效率差得太多；美国靠加息吸干世界流动性、维持国内股市的"病态荣景"，民众生活成本"比两年前至少翻了一倍"，油价一涨就让川普和共和党丢掉参众两院和德州的政治阵地，而美联储十二月继续加息"几乎已经是板上钉钉"；俄罗斯这个能源大国因为炼化设施被乌克兰炸毁，很多城市居民"需要凭票去加油"。三条腿都在往各自的方向跑，这才是宣言只能当创可贴的原因。
