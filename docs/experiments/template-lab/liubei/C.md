# 刘备换到秦末能赢项羽，刘邦换到三国打不过曹操

作者认为这次互换是单向的：刘备顶替刘邦能打败项羽，刘邦顶替刘备却统一不了天下。最强的理由是胜负的分水岭不在人主而在对手——项羽的败因是自己不会用人，曹操则不是这类漏洞可钻的对手。最大的限定是刘备赢的并不是项羽本人，作者明确说他"打项羽那打不过，打项羽的手下还是没有问题的"。

## 正面战场没人打得过项羽，赢他只能靠逼他分兵

楚汉的胜负不取决于正面战场的强度，而取决于能不能把项羽一个人拖到好几个战场上。这意味着"换谁上"本身并不决定结果，真正决定结果的是打不打这套分兵的战法——作者直接说，跟项羽正面打，谁来都没戏。

刘邦的做法是开辟多个战场：北面有韩信，南边有彭越，后来又拉拢了英布。执行原则很简单——项羽走到哪儿就躲着他，项羽离开哪儿就在哪儿开战。这套打法之所以好使，是因为它绕开了项羽本人这个唯一的强点，专挑他不在的地方下手。

## 项羽的败因在自己不会用人，所以换谁当他的对手都难赢

项羽的问题不在战场而在帐下：韩信原本就在他那儿，他不用，所以他那儿没有人才。这意味着可被复制的不是刘邦的运气，而是项羽自己留出的漏洞——只要顶上来的人自己水平够硬，又能用好分兵这套战略，都能打败项羽。

作者强调"什么事儿他都是自己来呀"，后果是只有项羽本人势不可挡，他一离开，手下就都不难对付。这一点很早就有人看出来了：《史记》记载楚汉争霸初期，一个叫袁生的人建议刘邦派韩信去北面、自己再出武关，把项羽吸引过来，好处是"如此，则楚所备者多，力分"——楚军不得不分散兵力。刘邦把这个战略发扬光大，很快就打败了项羽。

## 刘备换到秦末能打赢项羽，因为这套战法要的三样他都有

分兵战法需要主帅会用人、能拉拢人、自己军事水平过得去，刘备三样都对得上，所以作者认为他完全可以照搬这套打法。这也是整个互换判断里更稳的一半：赢的条件是战略，不是刘邦这个具体的人。

素材里的对应关系很直接：刘备也善于用人，可以用韩信开辟第二战场；他的人格魅力也很大，能团结彭越、劝降英布；他本人的军事水平也不错。至于项羽，作者说他输是输在自己，问题太致命了。

限定在项羽本人身上：刘备能打赢的是分兵之后的楚军，不是项羽。作者的原话是"打项羽那打不过，打项羽的手下还是没有问题的"——所以这个结论成立的前提，是他不必在正面战场上解决项羽。

## 刘邦换到三国，连起家这一步都走不通

刘邦和刘备的起点可以说是一样的：草根出身，没有根基，没有本钱。差别在于秦末还有一条共同的路——大家一起灭秦，就能成为一方诸侯；东汉末年这条路没有了，讨伐董卓讨了也没什么用。这意味着两人的差距不是从战场开始的，而是从"靠什么获得资本"这一步就开始了。

对手的量级也不一样。作者说，就算是孙权，都比项羽难对付多了，更不要说曹操——曹操家大业大，人口多，兵力强，军事水平又高。在三国稳定期，刘邦没有什么现成的入场位置。

## 就算刘邦不犯夷陵的错，也补不平曹魏的君臣与兵力

作者判断刘邦应该不会像刘备那样——关羽死了，他就去打荆州，打夷陵之战，打得一场大败。但避开这个错误并不改变结果，因为差距不在某一次决策，而在对手的体量与人才结构。

素材把曹魏的条件列得很硬：君臣齐心，将领优秀，兵力强大又精良。作者的反问是"你凭什么赢"，措辞也留着余地——"恐怕刘邦也没有什么道理能打败曹魏吧"。同一句判断还给到了更高的天花板：换成曹操这样的对手，你别说刘邦，就算是李世民、刘秀，也没办法带着蜀汉一统天下。

于是两问落回同一处：刘邦在秦末能统一天下、刘备在三国不能，是因为对手不一样。项羽这样的对手不难赢，而曹操不是项羽。
