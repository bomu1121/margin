# 美国停建数据中心的争论，卡住的不是电价而是电网增量

作者认为，美国把电价上涨算在数据中心头上、由此主张停建，是一次被错误评估推着走的政策反应；真正的约束不是数据中心该不该建，而是发电和电网的增量跟不上，AI 资本只能挤进现成电网抢资源。最硬的证据在 PJM：容量拍卖让居民为尚未建成的电厂和尚未出现的用电需求提前买单。但要打个折——节目自己也承认，ITIF 引用的数据并没有乱写，只是有选择性，所以这是一场关于归因口径和统筹方式的争论，而不是谁能拿出对方造假的证据。

## PJM 的容量拍卖，把还没出现的用电需求变成了眼下的电价

美国数据中心集中区的电价压力，走的不是"用电多了电价就涨"的直路，而是一条提前定价的机制路径。理解这一点才能明白：为什么数据中心还在图纸上，账单已经先到了居民手里。

弗吉尼亚、俄亥俄、宾夕法尼亚与新泽西共用一个跨州的 PJM 电网，而这个电网的容量拍卖机制是最饱受诟病的，连 ITIF 也承认这个机制有问题。机制本身是提前估算未来的用电高峰，然后锁定供电承诺：电发多少就得用多少，为了避免多发电，买家必须提前去竞标、买足够的供电承诺。人口和产业比较稳定时很好算，但 AI 数据中心都是狮子大开口，未来负荷预期陡增，拍卖价格就上去了。市场监测机构分析认为，PJM这个峰值负荷预测的大幅上调，导致拍卖价格大幅飙升，跟数据中心制造的预期有很大关系。

## 气价和电网改造能解释一部分电价，但解释不了 2023 年以后的居民零售电价

ITIF 把电价主要归给天然气价格和电网自身的投入，这个框架能说明成本为什么会涨，却说明不了居民零售电价在气价低位时还在涨。也就是说，数据中心的账不能全算在它头上，但也不能被这个框架完全排除。

报告的依据是两条。一条是美国发电45%靠天然气，所以电价主要跟天然气价格相关——作者承认"有一定的道理"，但从 2023 年开始气价一直徘徊在低位，这一条就断了。另一条是基建投资不能算在数据中心头上：数据中心没有承包电网，电网扩容是因为能源供应不稳定，可再生能源有间歇性，需要更多备用容量，而应对极端情况的燃气调峰电厂本来效率就低，遇到气价上涨，发电成本就被推高；这几年电网自己的资本开支两位数增长，大头是燃气轮机价格翻倍、老旧设备更新以及防火抗风等电网加固，真正用于数据中心的投入占比很少。它举的例子是缅因州：几乎没有大型数据中心，电价照样大涨，成因是灾害损失、气价上涨和绿电改造。

作者对这几条的总评只有一句——没有乱写，但是呢有选择性。所以问题不在单条理由真假，而在这些理由覆盖了哪一片地方、哪一段时间。

## ITIF 的论据没造假，但全国平均值和一个有利的时间窗抹平了集中州的压力

这份评估之所以显得有力，靠的是口径：全国平均、十五年长窗口。换成数据中心集中的州、换成 2019 年以后的短窗口，结论就松动了。这意味着"评估错误"这顶帽子两边都能戴，谁也没法靠对方的数字把对方一票否决。

最典型的是那个跌幅。剔除通胀因素，2010年到2025年，电价实际还跌了6%，但时间点选得有点鸡贼：数据中心大幅扩张的 2019 年以后，剔除通胀的涨幅还是有 3%；而且用的是美国全国平均值，显然该讨论的是数据中心集中那几个州涨了多少。作者专门去翻它引用的劳伦斯伯克利国家实验室报告《零售电价的趋势和推动因素》，核对结果是没有乱写，但是呢有选择性——这是一份全国范围的报告，并不反映数据中心集中州的真实承压情况。德州是另类，风光绿电装机量大、电力市场相对独立，涨幅比较温和；弗吉尼亚、俄亥俄、宾夕法尼亚与新泽西共用一个跨州的 PJM 电网，压力就完全是另一回事。

立场也被点了出来：ITIF 的赞助者里有建数据中心的、卖芯片和算力的科技巨头，也有卖配电与工业设备的厂商，所以它天然靠近产业利益、倾向于放开 AI 基建扩张。作者的反问是，照这个逻辑推下去，等于说美国老百姓太好忽悠，媒体说什么就信什么，误伤了科技中心。

## 真正的瓶颈是发电和电网的增量跟不上，AI 资本只能挤进现成电网抢资源

电价矛盾的根子不在数据中心的用电量，而在增量与存量之间的落差：新增发电和电网跟不上，资本自然转向现成的电网。这决定了冲突会集中在人口稠密区，而不是地广人稀的荒地。

人口稠密的地方本来就有现成的光纤、输配电线路、变电站，还有供水、市政配套，建设省事儿、项目周期短、商业变现快，现成的便宜，谁不占谁傻蛋，所以大家都往这些地方挤，而不是去地广人稀的地方新建基础设施。代价是必须跟普通用户竞争现有电网，加上缺乏自上而下的空间统筹，资本扎堆的结果是局部电网过载、扩容成本飙升，再叠上噪音污染、水资源争夺，科技公司跟社区民众的矛盾自然就会爆发。

ITIF 对这套结构有一条反向主张：数据中心落地速度没那么快、增长是渐进的，本身还能帮负荷管理——电网按峰值设计，数据中心只要避开峰值，就能在不增加需求的情况下提升整体利用率、摊薄现有用户的成本；电力部门甚至可以要求数据中心交押金、签长约、设低消，跑路还赔偿，把基建成本还给科技巨头自己。节目没有正面反驳这套设计，只是把矛头指向机制和统筹。

## 东数西算的差别在于有没有自上而下的空间统筹，缺了它成本就会甩给普通人

中美在这件事上的分野不是建不建，而是算力往哪儿放、由谁定。作者认为东数西算的意义正在于用国家级规划替代资本对现成节点的争抢，这正是美国那套"自发抢占"缺的一环。

东数西算把算力枢纽、尤其是对时延不敏感的业务，向西部有序引导，部署到能源和气候条件都适宜的地方，防止资本盯着现有的节点去抢占便宜、导致扎堆失衡。作者由此收口：AI 是重资产、重电力、重基建的大项目，没有电网、能源和空间布局的统筹规划，只靠市场自发去抢占现有资源，最容易把成本甩给普通人；而普通人在政治势力的引导下，又可能导致国家政策出现失误，错失科技风口。

这里要留一个限定：这是作者的判断，素材里没有给出东数西算的成本或落地数据，也没有把美国那几个集中州的电价涨幅和西部枢纽做同口径比较。
