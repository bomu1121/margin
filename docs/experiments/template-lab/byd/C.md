# 海牙禁令只锁唐i7一款车：路虎用外观设计权起诉比亚迪，挡的是门不是路

荷兰海牙地区法院判比亚迪唐i7侵犯路虎卫士的欧盟外观设计权，但这份禁令的实际杀伤面很窄——它只锁一款主攻英国市场、而欧盟管辖不到的车型。作者认为最强的一条理由不是法律，是商业现实：路虎自己正处在营收降两成、纯电车型跳票两年的转型困局里，比亚迪2025年研发投入634亿元、在英国注册量已是2024年的近六倍。最大的限定是，以上都属于节目的判断，禁令在欧盟境内仍然有效，唐i7进欧盟这条路确实被堵住了。

## 禁令的杀伤半径比看上去小：欧盟判决管不到唐i7的主场英国

这份裁决最容易被误读成“欧盟封杀比亚迪”的起点，但它真正的抓手只有一款车。禁令是车型特定的，只针对唐i7这一款，而唐i7主要面向英国市场，英国已经脱欧；作者认为欧盟法律对英国市场没有管辖权，所以这次败诉不构成对比亚迪欧洲业务的整体打击。这意味着禁令的象征意义大于实际封锁效果，节目里给出的原话是比亚迪在欧洲销售的其他车型“完全不受影响”。

事实链条本身是清楚的：荷兰海牙地区法院在十月二十日的裁决中认定，比亚迪唐i7侵犯了捷豹路虎在欧盟注册的卫士外观设计权，法院列出的相似点为方正的车身轮廓、平直的车顶，还有方形轮拱等等特征；判决结果是禁止比亚迪在欧盟境内进口、制造、销售和交付唐i7。也就是说，相似点认定和禁令范围都限定在这一款车上。

反过来说，这个限定只对欧盟境内有效。只要唐i7的主战场在英国，这份判决就更多是姿态而非实质封锁——前提是“主要针对英国市场”这个定位成立。

## 方正车顶和方形轮拱是结构决定的，相似不等于抄袭

外观撞脸不等于抄袭，这是作者的第二个判断，也是他对侵权逻辑最实质的反驳。理由是结构约束：SUV同质化本来就是市场的常态，硬派越野更是如此；想要保证通过性、车内头部空间，天然就会走向方正车身、平直车顶、方形轮拱这套结构，而这套结构的鼻祖是二战时代的吉普车。按这个推理，“长得像”更接近品类共性，而不是某一家可以主张独占的独创。

作者用产品代差把这个判断推到极致：说比亚迪抄袭路虎，就等同于说苹果抄袭诺基亚。节目里还提到路虎方面拿出的理由是“比亚迪方程豹的外观是对路虎的抄袭”，作者对这个说法的回应是反问式的——不是比过比不过或者谁像谁的问题。

需要留一分余地：作者谈的是“同质化不等于抄袭”这条逻辑，并没有论证两款车在具体设计细节上毫无对应关系；法院恰恰是在细节层面作出了相似认定。

## 路虎这次起诉更像衰退者的盘外招，而不是一场有底气的维权

时间节点确实特别——“咱董哥刚走”，欧洲因为没上桌吃饭在门口狗叫，荷兰这时整出禁令，很容易让人往地缘上想。但作者的判断是相反的：整体和宏观地缘层面关系不大，就是路虎在利用欧盟这个搅屎棍，恶心打压比亚迪。这个判断的重要性在于，它把事件从“中欧博弈”降级成了“一家车企的自救动作”。

支撑这个判断的是路虎自身的账和股权史。二六财年捷豹路虎的总营收为二百二十九亿英镑，同比下降百分之二十点九，全球批发销量为三十点七九万辆，同比下滑百分之二十三点二；作为对比，去年比亚迪宋一款车全球销量就有三十八万辆。反过来，比亚迪已经反攻到了路虎的欧洲大本营：2025年全年，比亚迪在路虎诞生地英国，注册了51422辆，是2024年的近六倍；今年前四个月，销量再度暴涨124%，正式超过特斯拉，成为英国最大的电动汽车品牌。压力之下，路虎启动了全球自愿离职计划，目标在两年内削减四千个岗位。股权侧更直白：路虎在十五年内被交易了三次——94年宝马收购捷豹路虎，2000年宝马以18亿英镑又把路虎卖给了福特，2008年福特又以23亿美元把路虎打包卖给印度塔塔。作者据此强调，捷豹路虎的百分之一百股权都在塔塔集团手上，说路虎是三哥车没有任何毛病。

## 真正的差距在研发：路虎的电动化要绕道塔塔，再绕回中国供应链

路虎的问题不是不想转型，是没实力、转得太慢——作者对“路虎不愿电动化”这个常见说法给的是另一种解释，而且他把原因落在研发投入和供应链选择上，而不是品牌态度上。比亚迪之所以能做到不断的技术突破，是因为每年都投入大量资源搞研发：仅2025年一年，比亚迪的研发投资就高达634亿元，研发人员12.77万，电池、电机、电控、芯片全部自研。

对照面是路虎的电动化路径。路虎在2024财年就启动了名为“重塑未来”的五年计划，总投资规模在1300亿人民币以上，但作者认为它的思路是买现成的：既想要奇瑞的生产能力，又想要【听不清】的智驾，又想要宁德的电池，还要营销自己的恒河逼格；中间还有一个魔鬼细节，路虎要扶持恒河的产业链，最终把电池锁定给了塔塔集团，而塔塔集团的电池元器件基本上都需要从咱们手里进口。这么绕来绕去，效率能高才怪，最终导致车辆难产——纯电揽胜原定于2024年前后就进入展厅，一直跳票了两年，最新的规划是到明年三月才能上市。

这里要收一句：1300亿的五年计划本身不是小数，作者质疑的是这笔钱花出去的方式，而不是路虎没投钱。

## 围剿式诉讼挡不住产品迭代，诺基亚当年也没挡住苹果

今天路虎在荷兰发起的起诉，在作者看来本质上仍和当年诺基亚围剿苹果如出一辙——这是他对事件性质的最终定位：不是一次普通的知识产权纠纷，而是旧秩序对新进入者的多线围剿。太阳底下没有新鲜事，这个类比的分量在于结局已知：围剿没能阻止苹果。

历史被复述得很具体：零九年十月，在美国特拉华州联邦法院，诺基亚起诉苹果侵犯了十项专利，包括无线数据、语音编码、安全加密等技术，这些都是手机最为基础的功能；除了美国本土，在英国、德国、荷兰等地诺基亚也全面开花，要求苹果相关产品下架并禁止进入相关市场。作者同时点出了两点差别：路虎毕竟不是当年的诺基亚，只敢在一款没有上市的车上做文章；而比亚迪还要比当年的苹果更强。数字上，二零二五年，特斯拉在欧洲整体销量下滑百分之二十七，但比亚迪销量达到十八点八万辆，暴涨百分之二百六十九，且仍然在大幅度增长。

类比的边界也在这里：诺基亚当年的专利是通信基础功能，覆盖面远大于一款车的外观设计，所以“结局会一样”是节目的推断，不是已经发生的事实。
