# 页面配色层级：从“全是近白”改成三层纸面

> 状态：2026-11-16 已落地浅色/暗色两套 token，真机截图与文字审计已完成。
> 范围：笔记阅读页的模块背景（顶栏、左侧栏、正文、右栏）为主；token 是全局的，其他页面会一起换色。
>
> **二次调整（2026-11-16）**：用户反馈左右栏 `--rail` 在 340px 大面积上偏深、偏闷；浅色 rail 已退回 `--paper #f4f1e8`，暗色 rail `#12100d → #1a1712`。第 1–6 节保留第一次落地的记录，当前数值以第 7 节为准。

## 1. 结论

旧配色不是“颜色不好看”，而是**明度层级反了**：

| 模块 | 旧背景 | 相对关系 |
| --- | --- | --- |
| 左侧栏 | `#ffffff` | 最亮 |
| 正文阅读区 | `#f6f7f4` | 中间，偏绿灰 |
| 右侧栏 | `#f1f2ef` | 更暗 |
| 顶栏/画布 | `#f6f7f4` | 和正文相同 |

实测对比：正文/右栏 **1.045:1**，正文/侧栏 **1.075:1**。三者几乎同白，只能靠 1px 的 `#dfe2de` 线分区。用户感知就是“模块之间没有关系、正文发灰、侧栏反而最抢眼”。

新方案是三层纸面：

| 层级 | 语义 | 浅色 | 暗色 |
| --- | --- | --- | --- |
| `--paper` | 画布 / 顶栏 | `#f4f1e8` | `#0c0b09` |
| `--surface` | 正文阅读面 / 卡片 | `#fffdf8` | `#211d16` |
| `--rail` | 左右栏 / 导航 | `#ece8de` | `#12100d` |

- **正文最亮**，阅读面先从背景里“抬”出来；
- **左右栏统一后退**，导航和辅助信息不再和正文抢亮度；
- 三层同一暖色相，不再出现“侧栏纯白 + 正文偏绿”的割裂；
- 线色改为暖灰 `#e2dccf / #c9c0ae`，与纸面同温。

新实测：正文/右栏 **1.204:1**，正文/画布 **1.111:1**；暗色正文/右栏 **1.132:1**，正文/画布 **1.173:1**。

## 2. 文字对比度

旧 `readability.css` 把 `--ink-3` 固定成 `#646c77`，是按旧 `#f6f7f4` 调的（4.94:1）；换暖纸后它掉到 **4.34:1**。这次一起修：

| 文本 | 旧 | 新 | 新对比度 |
| --- | --- | --- | --- |
| `--ink-3` 浅色 | `#868c93` | `#686055` | 纸面 5.48 / 右栏 5.06 |
| `--ink-3` 暗色 | `#828b9a` | `#9a9080` | 正文 5.33 / 右栏 6.04 |
| 正文 `--ink` 浅色 | `#14171a` | `#1b1813` | 正文 17.41 |
| 正文 `--ink` 暗色 | `#e9e7e1` | `#eee9df` | 正文 13.86 |
| `--gold` 浅色 | `#a06d12` | `#8a5d0c` | 纸面 5.09 / 右栏 4.70 |

顺带把事实右栏残留的 9.5–11.5px 小字（`rail-tabs`、`rail-fact-domain`、`rail-fact-meta/state`、`rail-fact-sep`）统一到 **12px**；浅色页面审计从 31 个未达标变为 **0 <10px / 0 <12px / 0 <4.5:1**（237 个文本节点）。

## 3. 为什么是这三层：调研依据

1. **Material 3 用 tone-based surface 角色表达层级**，而不是给每块叠阴影/透明度；`surface` 是画布，`surfaceContainer*` 从低到高表达容器强调度。阅读面用更高 tone，导航栏用更低 tone，和我们的三层映射一致。参考：[Material 3 color roles](https://m3.material.io/styles/color/roles)。
2. **Apple HIG 的暗色层级只用颜色，且限制在三级**：base / elevated / higher；暗色下 elevated 比 base 更亮，而不是靠阴影。我们的暗色把正文提到 `#211d16`、左右栏压到 `#12100d`，正是这个方向。参考：[Apple HIG Color](https://developer.apple.com/design/human-interface-guidelines/color)。
3. **WCAG 2.2**：正文/界面文本至少 4.5:1；本次新 token 的次级文本在纸面/右栏都 ≥4.5，正文 ≥13.8。参考：[WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
4. 长文阅读不追纯白：暖纸 `#fffdf8` 比 `#ffffff` 低一点眩光，同时保持正文足够亮；左右栏用更深的同色相，避免“纯白导航栏比正文更亮”的倒置。

## 4. 模块落地

| 模块 | 背景 | 说明 |
| --- | --- | --- |
| 顶栏 / 画布 | `--paper` | 顶部 chrome 退到画布 |
| 左侧栏 | `--rail` | 从纯白改为次级纸色 |
| 正文 `.note-layout` | `--surface` | 阅读面最亮 |
| 右栏 `.rail` | `--rail` | 与左栏同级，不再另造一个近白色 |
| 卡片/标签 | `--surface` + `--line` | 依靠线而不是不同白度区分 |
| 浮层/弹窗 | `--surface` | 仍高于画布 |

代码位置：

- `src/styles/app.css`：浅色/暗色 token、`.sidebar` 背景、`.note-layout` 阅读面；
- `src/styles/readability.css`：`--ink-3` 与 12px 下限；
- `src/styles/facts.css`：事实右栏小字尺寸与分隔符颜色。

## 6. 诚实清单

- 这次改的是**全局 token**，不只是笔记页；其他页面（事实、史料、制作台、任务详情）会一起变暖。只对笔记页和任务详情做了截图/文字审计，没有逐页重新做几何审计。
- 暗色只做了截图和文字审计；没有做暗色下每个模块的几何/色彩盲模拟。
- 事实卡片在暗色审计里的 1.19:1 是工具侧异常，实际计算颜色 13.86:1；在修工具前不能声称暗色审计全绿。
- 暖纸色是产品审美选择，不是“唯一正确答案”；如果更喜欢冷灰，可以只替换 `--paper/--surface/--rail` 三个值，层级关系保持不变。
- 没有做对比度仪/真实屏幕校色；数值来自 sRGB 相对亮度公式与浏览器计算样式。

## 7. 二次调整：侧栏 rail 提亮（2026-11-16）

### 7.1 结论

第一次把“左右栏后退”实现成整列 `#ece8de`。在笔记页 340px 左栏 + 302px 右栏的大面积上，它不再是“后退”，而是一圈米色边框；和正文 `#fffdf8` 并排时显闷、显脏。后退应该靠 1px 线和正文的亮度差，不是把整列压暗。

二次调整：

| 层级 | 浅色 | 暗色 |
| --- | --- | --- |
| 画布 / 顶栏 | `--paper #f4f1e8` | `--paper #0c0b09` |
| 左栏 / 右栏 | `--rail = --paper #f4f1e8` | `--rail #1a1712` |
| 正文 / 卡片 | `--surface #fffdf8` | `--surface #211d16` |

浅色从三层纸面变成两层：侧栏与顶栏同温，正文是唯一的亮面。暗色仍保留 rail 中间层，但比原来的 `#12100d` 提亮一档，避免侧栏接近纯黑。`--surface` 不动。

### 7.2 对比度

- 浅色 surface/rail **1.111**（旧 1.204）；rail/paper 1.0；`--ink-3` 在侧栏 **5.48**（旧 5.06）；正文 17.41。
- 暗色 surface/rail **1.065**（旧 1.132）；`--ink-3` 在侧栏 **5.68**（旧 6.04）；正文 13.86。
- 右栏卡片 surface on rail 1.111；卡片仍靠 1px `--line` 和状态左线，不靠底色。
- 浅色侧栏与顶栏同色，边界靠 `.sidebar` / `.rail` 的 1px `--line`；这是两层纸面的代价。

### 7.3 交互

- `--sb-hover` 从“ink 5.5% + surface”改为“ink 4% + paper”，否则 paper 侧栏上的 hover 几乎不可见；`--sb-press` 同步改为 8% + paper。
- `.rail-copy:hover` 从 paper 改为 surface，避免在 paper 侧栏上不可见。
- 标签板本身已经是 surface；这次改动影响左栏、右栏和标签页左栏，不改变正文。

- 右栏卡片的分离度从 1.204 降到 1.111；事实卡/空态在纸色上仍可读，但没有逐页截图复核。
