## 2026-11-17 全局宽度收敛

用户反馈事实库、史料库、史料详情三页的左右边距差异过大。核查后确认不是有意的层级，而是各页在自己建的时候各自写死了 `max-width`：

| 页面 | 改前 | 改后 |
| --- | --- | --- |
| 事实库（索引） | 1000px；左右 30px | 1120px；左右 30px |
| 史料库（索引） | 1120px；左右 30px | 1120px；左右 30px |
| 事实详情（阅读） | 980px；左右 34px、上 26px | 980px；左右 30px、上 24px |
| 史料详情（阅读） | 900px；左右 30px、上 20px | 980px；左右 30px、上 24px |

统一成两级，而不是四页一个宽度：

- `--index-width: 1120px`：事实库/史料库这类索引页，容纳筛选、搜索和行内元信息。
- `--detail-width: 980px`：事实详情/史料详情这类阅读页，控制正文行宽。
- `--page-pad-x: 30px`：四页统一左右内边距；≤980px 时统一 16px。
- 索引与阅读两级相差 140px，是有意保留的层级；同层页面现在完全同宽。

实测（1660×1202，app 左栏 240 / 主区 1420）：

- 事实库 `.facts-head`：x=390、w=1120；史料库 `.sources-head` / `.source-index-list`：x=390、w=1120。
- 事实详情 `.fact-detail-top/head/layout`：x=460、w=980；史料详情同三项也是 x=460、w=980。
- 四页 `document.body.scrollWidth = 1660`，无横向溢出。
- `audit-text`：事实库 381、史料库 103、史料详情 90、事实详情 109 节点，全部 0 个 <12px、0 个低对比。
- 1440 截图：`214-facts-width-1440`、`215-sources-width-1440`、`216-source-detail-width-1440`、`217-fact-detail-width-1440`。

边界：如果希望四个页面完全同宽，需要再统一成一个宽度；当前选择“索引 1120 / 阅读 980”的两级规则。只改了这四个知识库页，其他页面未纳入；没有做暗色/1040 全页复检。
