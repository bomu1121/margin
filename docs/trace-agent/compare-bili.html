1 · 复合主张两边都没拆

1–3 是一条句子塞了 2–4 个断言；旧流水线拿一句细节差异判「争议」，新 agent 拿一份官方文件判「可印证」，都没覆盖整句。

2 · 单循环把证据串位了

第 7 条（空管）拿到的是第 8 条「这就是生活」的引文，第 8 条拿到的是第 7 条空管报道；程序只校验“引文存在”，查不出“引文属于哪条主张”。

3 · 旧流水线把细节差异当争议

1/2/3/10 的旧 verdict 是 contradicts，引文多是“补了限定/换了数字”，不是真冲突；FACT_AUDIT 已记录过同类误判。

4 · 新 agent 更保守，但选源不稳

4/5/9/10 判「弱源」，其中 5/9 有更直接的旧来源；它还没有“来源相关性 + 权威性”的评分。

这次不是谁替代谁：旧流水线更会逐条隔离，agent 更会找一手来源。
