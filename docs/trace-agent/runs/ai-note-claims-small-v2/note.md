# 官渡：胜负不在人数

官渡一战，曹操击败袁绍。袁绍兵力占优，胜负本该向另一方倾斜，但真正的着力点在乌巢——曹操烧毁乌巢粮草，袁绍军随即溃败。

这一转折说明，优势兵力的前提是补给跟得上。粮草一断，人数反成负担：聚得越多，越难维持。战后曹操坑杀袁绍降卒，把胜利又推深一层，不只是击溃对手，还要断掉其重新集结的可能。

素材只留下这三步：兵多、焚粮、杀降。中间的调度、时日在材料里都没有，只能存疑。
