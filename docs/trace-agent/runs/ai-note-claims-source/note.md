# 九个字里的官渡

《三国志·武帝纪》写到官渡之战的收尾，只用了一句：“公至延津，绍众大溃。”陈寿没有铺陈战况，也没有评议谋略，只交代了位置与结果：曹军抵达延津，袁绍的部众就此瓦解。曹操在官渡击败袁绍这件大事，正史留下的画面几乎就停在这几个字上——地名落定，众心先散。越是大战，笔越轻，胜负的重量留给读者自己补。后来的人记得“官渡”二字，而这九个字，就是它最短的注脚：一句抵达，一句溃散，其余尽在不言中。
