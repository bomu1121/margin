> 一段视频口播里的推荐：一个开源项目，让主机、掌机游戏以「原生移植」的方式跑在电脑和手机上，不是模拟器。

## 它是什么

- 一个**开源**项目，素材里说它上线**两周就拿到 4.1k stars**。
- 用途：把各类**主机、掌机游戏原生地搬到电脑上和手机上玩**。
- 关键定位：**它不是模拟器**，而是让各个系统对应的原生程序、游戏代码直接运行。
- 素材来自今年下半年的观察——作者觉得这段时间 AI 技术似乎有一个质的提升，冒出一大堆离谱又好用的开源项目。

```figure
kind: compare
title: 模拟器 vs 原生移植
left: 模拟器 | 在中间层转译硬件与系统
right: 原生移植 | 直接运行原生程序与游戏代码
left-item: 画质/帧率 | 相对吃亏
right-item: 画质/帧率 | 更好，很多游戏能开 2K、稳定 60 帧
note: 素材的说法是原生方式在画质和帧率上都优于模拟器。
```

## 上手与体验

- 本期提供的 **Windows、Mac 版本是已经编译好的中文汉化版**，打开就能直接用，不用自己折腾编译。
- **手柄会自动适配**，不用手动配。
- **接上电视开全屏**，就是一台主机的体验。
- 性能上：画质、帧率比模拟器更好，**很多游戏能直接开到 2K 分辨率，甚至还能稳定 60 帧**。

## 作者的语气和保留

- 通篇是「有需要可以自己去试试看」的推荐口吻，不是评测数据。
- 关于「那个游戏六」会不会真被移植成功、能不能直接在 PC 上玩，素材里只是**猜测式调侃**（"感觉真有点可能"），没有确认。
- 素材没有给项目名称、仓库地址或下载链接，只提到可以自己去找来试。
